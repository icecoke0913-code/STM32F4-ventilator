# 硬件连接记录

## 供电原则

- 电机电源与编码器逻辑电源分开。
- STM32、TB6612、编码器、传感器和显示屏必须共地。
- 编码器使用3.3V供电，A/B相需要上拉到3.3V。
- MQ-2加热端使用5V，模拟输出进入STM32前不得超过3.3V。
- 电机电源端增加储能和高频去耦电容。

## 编码器线序

依据产品图片：

- 红：电机电源正。
- 白：电机电源负。
- 黑：编码器电源正，3.3V。
- 蓝：编码器电源负。
- 黄、绿：编码器A/B反馈；具体方向在M5阶段实测确认。

## 电机裸线转接方法

实物电机的六根线为剥皮上锡的裸线，不直接插入STM32或开发板排母。推荐制作转接线：

- 红、白两根电机动力线：焊接到较粗导线或2P接线端子，再连接TB6612的AO1/AO2；不接STM32。
- 黑、蓝、黄、绿四根编码器线：焊接或压接到杜邦母端子，并套入1P或4P胶壳；也可以焊到2.54mm排针转接板后再接杜邦线。
- 每个焊点单独使用热缩管绝缘，外层再做一次线束固定，避免裸铜短路和电机振动造成断线。
- 临时联调可以在面包板上使用螺钉接线端子转2.54mm排针，不建议用手拧线或胶带直接包裹。

线色与连接：

| 电机线色 | 功能 | 连接位置 |
|---|---|---|
| 红 | 电机端1 | TB6612 AO1 |
| 白 | 电机端2 | TB6612 AO2 |
| 黑 | 编码器电源正 | STM32 3.3V |
| 蓝（实物可能看起来偏紫） | 编码器电源负 | 系统GND |
| 黄 | 编码器相位信号 | PC6 / TIM3_CH1，外接上拉到3.3V |
| 绿 | 编码器相位信号 | PC7 / TIM3_CH2，外接上拉到3.3V |

黄、绿对调只会改变计数方向，可在M5阶段根据正转方向调整。编码器A/B为开漏输出，黄线和绿线各使用一个4.7kΩ～10kΩ电阻上拉到3.3V。

## MQ-2分压要求

- 模块VCC接5V，GND接系统地。
- 只使用AO，第一阶段不使用DO。
- AO先经过约0.6倍分压再进入PC0，例如AO经10kΩ串联到PC0、PC0再经15kΩ接地。
- 分压后的理论最大值为5V × 15/(10+15) = 3.0V。
- 正式接PC0前，先用万用表测量模块AO和分压节点电压。

## 已确认电机参数

- 型号：JGA12-N20-50B。
- 额定电压：6V；允许范围：3～12V。
- 空载转速：300 RPM；空载电流：40mA。
- 最大效率点：225 RPM、155mA、0.14kg·cm。
- 堵转电流：0.55A；堵转转矩：0.7kg·cm。
- 减速比：50。
- 编码器四倍频理论计数：1400计数/输出轴圈。

## 开发板原理图核对记录

- 资料：根目录 `stm32f407vet6.pdf`。
- MCU外部高速晶振：8 MHz。
- MCU外部低速晶振：32.768 kHz。
- 板载用户按键S1连接PA0，按下通过1 kΩ接到3.3V。
- 板载用户LED连接PA1，实际亮灭电平在M1阶段验证。
- P2 TFT接口：1=3.3V、2=GND、3=PB15、4=PB13、5=PB12、6=PB14、7=PC5、8=PB1；因购买的屏幕接口不匹配，本项目不使用该插座。
- 板载W25QXX：PA15=CS、PB3=SCK、PB4=MISO、PB5=MOSI。
