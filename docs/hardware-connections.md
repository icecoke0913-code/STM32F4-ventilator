# 硬件连接记录

## 供电原则

- 电机电源与编码器逻辑电源分开。
- STM32、TB6612、编码器、传感器和显示屏必须共地。
- 编码器计划使用3.3V供电；C1/C2输出类型及是否需要外接上拉留到M5依据资料或实测确认。
- MQ-2加热端使用5V，模拟输出进入STM32前不得超过3.3V。
- TB6612模块实物已带约10μF储能电容和小型去耦电容；M4使用模块现有电容。

## 电机与编码器实际六线映射

已根据购买的编码器转杜邦线转接板实物丝印确认。转接板丝印从左到右为：

```text
M2、VCC、C2、C1、GND、M1
```

| 线色 | 丝印 | 功能 | M4连接 |
|---|---|---|---|
| 绿 | M2 | 电机端2 | TB6612 AO2 |
| 橙 | VCC | 编码器3.3V电源 | 不连接，单独绝缘 |
| 黄 | C2 | 编码器相位2 | 不连接，单独绝缘 |
| 白 | C1 | 编码器相位1 | 不连接，单独绝缘 |
| 红 | GND | 编码器地 | 不连接，单独绝缘 |
| 黑 | M1 | 电机端1 | TB6612 AO1 |

M4只连接黑色M1和绿色M2。其余四根编码器线留到M5，当前全部悬空并分别绝缘。旧产品图片推断的线色映射不再使用。

## 电机转接线使用要求

电机原始六根线已通过专用转接线转换为杜邦接口，不再采用裸线临时连接。连接和移动转接线前必须先断开9V适配器、STM32 USB-C、ST-Link和USB转TTL。M5接入编码器前，需要单独确认C1/C2的电气输出类型以及是否需要外接上拉电阻，不能继续沿用旧产品图片的推断。

## M4 TB6612供电与接线

```text
9V适配器 → DC-DC输入
DC-DC 5V → TB6612 VM
STM32 3.3V → TB6612 VCC
STM32 GND、DC-DC GND、TB6612 GND → 共地
黑色M1 → TB6612 AO1
绿色M2 → TB6612 AO2
```

- 禁止把DC-DC的VIN或9V直通输出接到TB6612 VM或电机。
- STM32继续通过USB-C供电，不使用DC-DC给STM32反向供电。
- M4只使用TB6612 A通道，B通道不连接。
- M4固定使用`AIN1=高、AIN2=低`正转；方向不符合需求时，只能完全断电后交换AO1与AO2上的电机线。
- 初始安全状态为STBY低、PWM为0、AIN1低、AIN2低；上电或复位后电机不得自动旋转。

TB6612模块实物引脚按已确认照片方向从上到下为：

```text
左侧：PWMA、AIN2、AIN1、STBY、BIN1、BIN2、PWMB、GND
右侧：VM、VCC、GND、AO1、AO2、BO2、BO1、GND
```

## MQ-2分压要求

- 模块VCC接5V，GND接系统地。
- 只使用AO，第一阶段不使用DO。
- AO先经过约0.6倍分压再进入PC0，例如AO经10kΩ串联到PC0、PC0再经15kΩ接地。
- 分压后的理论最大值为5V × 15/(10+15) = 3.0V。
- 正式接PC0前，先用万用表测量模块AO和分压节点电压。

## DHT11接线要求

M3A使用三针DHT11模块，规划接线为：

| DHT11信号 | 连接位置 | 说明 |
|---|---|---|
| VCC | STM32 3.3V | 不使用5V，确保板载数据上拉电平安全 |
| DATA | PD0 | 单总线数据，驱动中动态切换开漏输出与输入 |
| GND | STM32 GND | 与开发板共地 |

- 三针模块通常带板载数据上拉，因此M3A不增加外部上拉电阻。
- 接线前必须按实物丝印确认VCC、DATA和GND顺序，不能按针脚位置猜测。
- M3A测试时MQ-2的AO和DO均不得连接STM32。
- DHT11运行中DATA线断开会稳定报告TIMEOUT，重新接回后无需复位即可恢复OK；两次重复测试均已通过。

## 已确认电机参数

- 型号：JGA12-N20-50B。
- 额定电压：6V；允许范围：3～12V。
- 空载转速：300 RPM；空载电流：40mA。
- 最大效率点：225 RPM、155mA、0.14kg·cm。
- 堵转电流：0.55A；堵转转矩：0.7kg·cm。
- 减速比：50。
- 编码器四倍频理论计数：1400计数/输出轴圈。

## 待确认项

- ST7735S实际显示方向、颜色顺序和坐标偏移。
- ST7735S最终校准：竖屏128×160，MADCTL=0xC0，X Offset=0，Y Offset=0，BLK高电平点亮，SPI2时钟5.25MHz。
- 首次白屏由显示通信线物理连接不良导致；断电重新插接后恢复。移动杜邦线前必须先断开USB-C、ST-Link和USB转TTL。
- MQ-2模块AO及分压节点的实测最大电压。
- DC-DC模块实际输入电压，以及5V/3.3V各路实测电压。
- TB6612开环挡位与空载运行已通过；未使用万用表测量5V或启动压降，未进行堵转、带负载或长时间运行测试。
