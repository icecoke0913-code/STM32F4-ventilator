# M4 TB6612开环电机控制设计

## 1. 目标与范围

M4在现有STM32F407VET6、FreeRTOS、USART1、ST7735S和DHT11工程基础上，使用TB6612FNG的A通道驱动JGA12-N20-50B直流减速电机，实现PA0按键控制的固定正转开环调速。

本阶段只验证停止、30%、50%和70%四个挡位，不接编码器、不测量实际转速、不实现PID、不测试软件反转，也不连接扇叶或其他机械负载。编码器测速与闭环控制留到M5，正式电机UI与LVGL移植留到M9。

## 2. 已确认硬件

### 2.1 电机

- 型号：JGA12-N20-50B。
- 额定电压：6V；允许工作范围：3～12V。
- 空载转速：300 RPM；空载电流：40mA。
- 最大效率点：225 RPM、155mA、0.14kg·cm。
- 堵转电流：0.55A；堵转转矩：0.7kg·cm。
- 减速比：50。

### 2.2 TB6612FNG模块

- VCC逻辑电源允许范围：2.7～5.5V。
- VM电机电源允许范围：2.5～13.5V。
- A通道持续驱动能力满足本电机0.55A堵转电流，但M4禁止主动堵转测试。
- STBY为低时，驱动输出进入高阻待机状态。
- 模块实物带约10μF储能电容和小型去耦电容，M4使用模块现有电容，不额外增加外接电容。

按已核对的模块背面照片方向，引脚从上到下为：

```text
左侧：PWMA、AIN2、AIN1、STBY、BIN1、BIN2、PWMB、GND
右侧：VM、VCC、GND、AO1、AO2、BO2、BO1、GND
```

M4只使用A通道，B通道引脚保持不连接。

### 2.3 电源模块

- 适配器输出：9V、最大0.6A。
- DC-DC模块输入范围：6～30V。
- DC-DC模块提供VIN直通、5V、3.3V和GND接口。
- 当前没有万用表，因此不能实测输出电压和负载时的电压跌落。
- 适配器0.6A额定电流只略高于电机0.55A堵转电流，供电余量有限，因此M4只允许短时空载测试，禁止堵转和带机械负载测试。

## 3. 供电与接线设计

### 3.1 供电架构

```text
9V / 0.6A适配器
        ↓
     DC-DC模块
        ↓ 5V输出
TB6612 VM → A通道 → 电机

STM32 USB-C供电
        ├─ 3.3V → TB6612 VCC
        └─ GND ─┬─ TB6612 GND
                └─ DC-DC GND
```

- TB6612的VM只连接DC-DC模块明确标注的5V输出。
- 禁止将DC-DC的VIN或9V直通输出连接到TB6612 VM或电机。
- TB6612的VCC连接STM32 3.3V，只为逻辑部分供电。
- STM32 GND、DC-DC GND和TB6612 GND必须共地。
- STM32继续使用USB-C供电，不从电机DC-DC模块反向供电。

### 3.2 STM32控制引脚

| STM32引脚 | 外设配置 | TB6612引脚 | 用途 |
|---|---|---|---|
| PB6 | TIM4_CH1 | PWMA | 20kHz PWM调速 |
| PB7 | GPIO输出 | AIN1 | 固定正转方向控制1 |
| PB8 | GPIO输出 | AIN2 | 固定正转方向控制2 |
| PB9 | GPIO输出 | STBY | 驱动器待机与使能 |

固定正转时使用`AIN1=高、AIN2=低`。M4不提供反转控制接口。若实物转向不符合最终安装需求，必须完全断电后交换AO1与AO2上的两根电机线，不能在M4通过软件反转。

### 3.3 电机实际六线映射

用户购买的编码器转杜邦线转接板，实物丝印从左到右为：

```text
M2、VCC、C2、C1、GND、M1
```

| 线色 | 丝印 | 功能 | M4连接 |
|---|---|---|---|
| 绿 | M2 | 电机端2 | TB6612 AO2 |
| 橙 | VCC | 编码器3.3V电源 | 不连接，单独绝缘 |
| 黄 | C2 | 编码器相位2 | 不连接，单独绝缘 |
| 白 | C1 | 编码器相位1 | 不连接，单独绝缘 |
| 红 | GND | 编码器地 | 不连接，单独绝缘 |
| 黑 | M1 | 电机端1 | TB6612 AO1 |

M4只连接黑色M1和绿色M2。橙、黄、白、红四根编码器线全部悬空并分别绝缘，留到M5重新设计和验证。

## 4. PWM与挡位设计

使用TIM4_CH1在PB6输出20kHz PWM。20kHz高于大多数人耳敏感范围，可减少低频PWM导致的可闻啸叫。

PA0每次产生一次有效按下事件时，挡位按以下顺序循环：

```text
停止 → 30% → 50% → 70% → 停止
```

- 上电和复位后初始挡位始终为停止，不自动旋转。
- 必须释放PA0后再次按下，才能切换下一个挡位；长按不能连续切换。
- M4不使用100%占空比，以降低首次联调时的供电和机械风险。
- 0%必须执行安全停机，而不是只保存一个软件挡位值。

## 5. 软件架构

### 5.1 电机BSP

新增独立驱动文件：

```text
firmware/SmartHood/BSP/Inc/bsp_motor.h
firmware/SmartHood/BSP/Src/bsp_motor.c
```

计划接口为：

```c
/* 初始化电机驱动，并确保电机保持停止 */
bool BSP_Motor_Init(void);

/* 设置固定正转占空比，合法输入范围为0～100 */
void BSP_Motor_SetDuty(uint8_t duty_percent);

/* 立即清零PWM并使驱动器进入待机 */
void BSP_Motor_Stop(void);
```

电机BSP只负责：

- 控制PWMA、AIN1、AIN2和STBY。
- 启动TIM4_CH1 PWM。
- 将百分比换算成定时器比较值。
- 限制占空比参数范围。
- 在初始化或PWM启动失败时保持安全停止状态。

应用层不直接操作TB6612引脚或TIM4比较寄存器。

### 5.2 任务组织

M4沿用现有`App_DefaultTask`完成PA0挡位切换，不新增`MotorTask`。当前只有按键事件和开环挡位，不存在周期闭环计算；新增任务会引入不必要的任务间同步。M5加入编码器测速或PID时，再评估独立电机控制任务。

原有`SensorTask`继续负责DHT11采集，不承担电机控制。

### 5.3 数据流

```text
PA0有效按下
     ↓
App_DefaultTask切换挡位索引
     ↓
得到0%、30%、50%或70%
     ↓
调用BSP_Motor_SetDuty()或BSP_Motor_Stop()
     ↓
TB6612 A通道驱动电机
     ↓
USART1输出本次状态日志
```

日志格式计划为：

```text
motor init ok, state=STOP
motor duty=30%, state=RUN
motor duty=50%, state=RUN
motor duty=70%, state=RUN
motor duty=0%, state=STOP
```

M4不修改ST7735S当前测试画面，不在TFT上增加电机挡位或转速显示。

## 6. 安全状态与错误处理

安全默认输出为：

```text
STBY = 低
PWMA = 0%
AIN1 = 低
AIN2 = 低
```

具体规则如下：

- CubeMX生成的GPIO初始输出必须使STBY、AIN1和AIN2为低。
- `BSP_Motor_Init()`开始时先执行安全停止，再尝试启动PWM。
- `HAL_TIM_PWM_Start()`失败时保持STBY低，并向应用层返回初始化失败。
- 初始化成功后仍保持停止，只有PA0有效按下切换到运行挡位时才使能驱动器。
- `BSP_Motor_SetDuty(0)`等价于`BSP_Motor_Stop()`：PWM比较值清零、方向引脚拉低、STBY拉低。
- 大于100%的输入在BSP内部限制为100%，防止比较值越界；正常应用流程只传入0、30、50和70。
- 按RST时，硬件复位和GPIO默认状态必须让电机停止；程序重启后不能恢复复位前挡位。
- 初始化失败或其他已知软件异常后不自动重启电机，必须保持停止。
- M4不实现堵转、过流、过温或编码器故障检测，不将缺失的安全能力描述为已经具备。

## 7. 实施边界

M4实施包含：

- CubeMX配置TIM4_CH1 20kHz PWM以及PB7、PB8、PB9安全初始状态。
- 新增带结构化中文注释的电机BSP。
- 在现有PA0按键逻辑中加入四挡循环。
- 增加清晰的USART1状态日志。
- 分阶段进行无电机和空载电机验证。

M4不包含：

- 编码器VCC、C1、C2和GND接线。
- TIM3编码器模式、转速计算或方向判断。
- PID闭环调速。
- 软件反转与制动模式比较。
- 堵转测试、带负载测试或长期可靠性测试。
- MQ-2接入。
- TFT电机页面或LVGL移植。

## 8. 验收方案

### 8.1 无电机构建与回归

先不连接AO1、AO2上的电机：

- Keil全量编译为0 Error(s)、0 Warning(s)。
- 构建日志确认TIM4和`bsp_motor.c`参与编译或链接。
- 烧录后输出电机初始化成功和停止状态日志。
- USART1心跳、PA0、PA1、DHT11和TFT保持正常。

### 8.2 空载首次上电

完全断电后接入黑色M1和绿色M2，电机固定并保持空载：

- 上电后电机不自动旋转。
- 按RST后电机立即停止，重启后仍保持停止。
- TB6612和电机没有异味、冒烟或短时间内明显异常发热。
- 不进行堵转，也不连接扇叶或机械负载。

### 8.3 挡位循环

通过PA0依次验证：

```text
停止 → 30% → 50% → 70% → 停止 → 30%
```

- 每次短按只切换一个挡位。
- 30%、50%、70%的空载转速表现出逐级上升趋势。
- 从70%切换到停止后电机停止，TB6612进入待机状态。
- 串口日志与实际挡位一致。
- 按住按键不能连续跳过多个挡位。

### 8.4 最终回归

- USART1日志正常，无明显交叉或乱码。
- PA1心跳正常。
- PA0按键输入和挡位切换正常。
- TFT保持M2最终测试画面。
- DHT11继续正常采集；断开DATA后报告TIMEOUT，重新连接后无需复位自动恢复。
- FreeRTOS任务持续运行，没有卡死、异常复位或明显调度异常。

## 9. 当前限制与安全要求

- 当前没有万用表，无法确认DC-DC的实际5V输出或电机启动时的电压跌落；必须依靠模块丝印严格区分5V与VIN。
- 电机由5V供电，低于6V额定电压，预期空载转速会低于标称300 RPM；M4只比较三个挡位的相对速度趋势，不以300 RPM作为验收值。
- 首次测试必须空载、固定电机并短时运行。
- 出现异味、冒烟、异常声音或明显发热时立即切断9V适配器和STM32供电。
- 改动电机线、TB6612线或DC-DC线之前，必须先断开9V适配器、STM32 USB-C、ST-Link和USB转TTL。
- 本设计只证明基础开环驱动可用，不证明系统具备堵转保护、过流保护或闭环稳速能力。
