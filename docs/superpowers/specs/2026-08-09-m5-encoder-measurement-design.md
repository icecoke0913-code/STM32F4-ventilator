# M5 编码器测速与 RPM 标定设计

## 1. 目标与范围

M5 在已完成的 M4 TB6612 开环 PWM 电机控制基础上，接入 JGA12-N20-50B 电机的 AB 相编码器，实现：

- 编码器电气接口确认与安全接线。
- 使用 TIM3 硬件编码器模式读取 C1/C2 正交信号。
- 判断输出轴旋转方向。
- 以 50 ms 周期计算计数增量和瞬时 RPM。
- 记录理论计数常数，并通过实测输出轴转数完成 RPM 标定。

M5 不包含：

- PID 闭环调速。
- 自动调节 PWM 占空比。
- 软件反转控制。
- 堵转、过流、过温或带机械负载测试。
- 正式 TFT UI 或 LVGL 移植。

## 2. 硬件连接

编码器转接线以实际转接板丝印为准：

| 线色 | 丝印 | 功能 | M5连接 |
|---|---|---|---|
| 橙色 | VCC | 编码器电源 | STM32 3.3V |
| 红色 | GND | 编码器地 | STM32 GND |
| 白色 | C1 | 编码器 A 相 | PC6 / TIM3_CH1 |
| 黄色 | C2 | 编码器 B 相 | PC7 / TIM3_CH2 |
| 黑色 | M1 | 电机端 | TB6612 AO1 |
| 绿色 | M2 | 电机端 | TB6612 AO2 |

编码器逻辑电源只使用 3.3V。首次测试时断开 TB6612 的 VM，仅使用 STM32 供电并手动转动输出轴。C1/C2 的实际输出类型和外部上拉要求尚未通过万用表确认，因此初次配置使用 STM32 输入内部上拉；若后续资料或测试证明需要外部上拉，必须在重新评估电平和接线后增加。

移动任何杜邦线前，先断开 9V 适配器、STM32 USB-C、ST-Link 和 USB 转 TTL。

## 3. 计数架构

采用 TIM3 硬件 Encoder Mode：

- `TIM3_CH1 / PC6` 接 C1。
- `TIM3_CH2 / PC7` 接 C2。
- 定时器硬件完成 AB 相正交计数，避免高频 GPIO 中断造成丢计数。
- 计数器使用 16 位无符号计数；软件使用有符号差值处理回绕。
- 应用采样周期为 50 ms，与后续 M6 目标控制周期保持一致。

理论编码器参数为 7 PPR、减速比 50、四倍频，因此理论值为：

```text
7 × 50 × 4 = 1400 counts / 输出轴一圈
```

该数值仅作为初始换算常数，最终以 M5 实测标定值为准。

## 4. 软件模块

### 4.1 `bsp_encoder`

独立 BSP 封装以下接口：

- 启动和停止 TIM3 编码器计数。
- 读取当前计数器值。
- 计算相邻采样点的有符号计数增量。
- 处理 16 位计数器回绕。
- 根据计数常数换算放大 10 倍的整数 RPM（`rpm_x10`），避免 ARMCC 浮点格式化依赖。

### 4.2 `motorTask`

新增独立任务 `App_MotorTask`，为后续 M6 PID 保留任务边界：

1. 启动 TIM3 编码器接口。
2. 记录初始计数。
3. 每 50 ms 读取一次计数并计算增量、方向和瞬时 RPM。
4. 累计 10 个采样点后，每 500 ms 输出一次串口统计日志。
5. M5 只测量，不写入 PWM，不改变 PA0 的 M4 挡位控制。

编码器启动失败时只记录一次错误并保持任务可恢复运行，不得通过错误路径提高 PWM 占空比。闭环阶段再定义“测速失效时停机”的系统策略。

## 5. 数据处理

50 ms 采样时 RPM 计算公式为：

```text
RPM = 计数增量 × 60 / (每圈计数 × 0.05)
```

程序内部使用整数放大 10 倍表示小数 RPM，例如 `rpm_x10=1234` 表示 `123.4 RPM`。日志同时输出原始计数增量、方向和 RPM，便于判断信号质量和标定误差。

计数器差值必须使用无符号减法后转换为有符号值，以保证短时间采样窗口跨越 0/65535 回绕时仍能得到正确方向和增量。

## 6. 分阶段验收

### M5-T1：手动计数

断开 VM，仅给编码器 3.3V；手动转动输出轴，确认计数变化、正反转符号相反、停止后计数保持。

### M5-T2：信号稳定性

在无 VM 状态下进行慢速、快速和正反转切换，确认无长期丢计数、方向反复跳变或信号完全不响应。

### M5-T3：低占空比电机测速

重新接通 TB6612 5V VM，依次测试 M4 的 30%、50%、70% 挡位；每个挡位短时运行并记录计数增量、方向、稳定 RPM、启动和噪声现象。

### M5-T4：RPM 标定

在稳定挡位运行固定时间（建议 30 秒），记录总计数和输出轴实际转数：

```text
实测每圈计数 = 总计数 / 实际输出轴转数
```

后续 RPM 换算统一使用实测每圈计数，并在 `docs/test-records.md` 中同时保留理论值和实测值。

## 7. 风险与限制

- 没有万用表时，不能把 C1/C2 输出类型描述为已实测确认。
- 编码器 VCC 禁止接 5V，避免超过 STM32 GPIO 可承受电平。
- M5 仍禁止堵转、带扇叶、带机械负载和长时间温升测试；当前 9V/0.6A 供电余量有限。
- 理论 1400 counts/圈不等于最终准确标定值。
- M4 的开环 PWM 仍由 PA0 控制，M5 测速任务不得擅自修改占空比。
