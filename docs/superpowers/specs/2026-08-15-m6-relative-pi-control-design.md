# M6 相对速度 PI 闭环控制设计

## 1. 目标与范围

M6 在 M5 编码器测速基础上，使用 TIM3 的 AB 相计数反馈控制 TB6612FNG 的电机 PWM。由于用户跳过了实际 CPR 标定，本阶段不验收绝对 RPM，而是验收两个相对计数目标的稳定性、阶跃响应和编码器故障停机。

本阶段包含：

- 50 ms 编码器采样与 PI 控制周期。
- 低档 `130 counts/50 ms` 和高档 `195 counts/50 ms` 两个相对目标。
- 30% PWM、300 ms 的软启动。
- 位置式 PI 加前馈、定点运算、积分抗饱和和 PWM 限幅。
- 编码器无计数故障检测、停止和故障锁存。
- PA0 短按循环：停止、低档闭环、高档闭环、停止。

本阶段不包含：

- 精确 190/220 RPM 控制或 CPR 重新标定。
- 自动模式、MQ-2 融合、LVGL、软件反转。
- 堵转、过流、过温、带扇叶、带机械负载或长时间温升测试。

## 2. 已确认的控制参数

| 项目 | 低档 | 高档 |
| --- | ---: | ---: |
| 目标计数 | 130 counts/50 ms | 195 counts/50 ms |
| 前馈 PWM | 50% | 70% |

计数目标来自 M5 的 50% 和 70% 空载实测趋势。它们是相对控制量，不通过未标定的 `1400 counts/rev` 宣称为精确 RPM。

公共参数：

- 控制周期：50 ms。
- 启动 PWM：30%。
- 启动时间：300 ms。
- PWM 输出范围：30%～90%。停止时强制为 0%。
- 初始定点参数：`Kp = 64/256`，`Ki = 4/256`。
- 运行方向：沿用 M4 已验证的固定正转；方向符号只记录日志，不参与误差绝对值计算。

## 3. 状态机

```text
STOP
 ├─ PA0短按 → LOW_START
LOW_START
 ├─ 30% PWM运行300 ms → LOW_PI
 ├─ PA0短按 → HIGH_START
 └─ 故障 → FAULT
LOW_PI
 ├─ PA0短按 → HIGH_START
 └─ 故障 → FAULT
HIGH_START
 ├─ 30% PWM运行300 ms → HIGH_PI
 ├─ PA0短按 → STOP
 └─ 故障 → FAULT
HIGH_PI
 ├─ PA0短按 → STOP
 └─ 故障 → FAULT
FAULT
 ├─ PWM=0，TB6612进入待机
 └─ PA0短按 → STOP
```

启动阶段不累计积分。进入 PI 状态时清零积分和上一周期误差，避免停止期间的历史误差影响重新启动。

## 4. PI 数据流

`App_MotorTask` 每 50 ms 执行一次：

1. 读取 TIM3 计数增量。
2. 取增量绝对值作为实际速度计数。
3. 计算 `error = target_count - actual_count`。
4. 更新积分并执行积分范围限制。
5. 计算 `correction = Kp * error + Ki * integral`。
6. 计算 `duty = feedforward + correction`。
7. 将 duty 限制在 30%～90%，再调用 `BSP_Motor_SetDuty()`。

PI 使用整数定点运算，不使用浮点数。D 项不启用，避免 50 ms 计数跳变放大噪声。

当 duty 已达到上限且误差仍为正，或 duty 已达到下限且误差仍为负时暂停积分，防止积分饱和。停止、故障和重新进入闭环时清零积分。

## 5. 故障策略

进入 PI 状态后，如果连续 500 ms 没有有效编码器计数，则判定为编码器断线、电机未起转或异常停止：

1. PWM 设置为 0%。
2. TB6612 进入待机。
3. 输出 `ENCODER_TIMEOUT` 日志。
4. 锁存 `FAULT` 状态。

不自动重试。故障状态下第一次 PA0 短按只清除故障并保持停止，下一次短按才重新进入低档启动。

故障测试不在电机运行中拔线，而是在断电后断开 C1/C2，重新上电启动并观察安全停机。

## 6. 模块边界

- `App_DefaultTask`：负责 PA0 消抖、按下沿识别和发送控制命令，不直接修改 PWM。
- `App_MotorTask`：唯一执行状态机、编码器反馈、PI 和电机 PWM 更新的任务。
- `bsp_encoder`：保留 TIM3 计数读取和增量接口。
- `bsp_motor`：保留 TB6612 初始化、固定正转、PWM 设置和安全停止接口。
- `Control/Inc/control_pi.h`、`Control/Src/control_pi.c`：新增纯算法模块，不访问 GPIO、TIM 或 FreeRTOS。
- `freertos.c`：保留现有 `motorTask`，不新增定时器、中断或 DMA。

## 7. 日志与验收

每约 500 ms 输出一次状态、目标、实际计数、误差、PWM、积分和故障标志。停止和故障分别输出 `STOP`、`ENCODER_TIMEOUT`。

低档验收：连续 10 秒实际计数保持在 `117～143 counts/50 ms`，无持续振荡，PWM 不超过 90%。

高档验收：连续 10 秒实际计数保持在 `175～215 counts/50 ms`，无持续振荡，PWM 不超过 90%。

阶跃验收：低档闭环短按切换高档，再短按停止；两个目标都应恢复稳定，期间无异常噪声、明显发热、系统重启或占空比持续上升。

## 8. 实施顺序

1. 新增 `control_pi` 模块，先完成 Keil 编译验证。
2. 将 `App_MotorTask` 从 M5 测速任务扩展为闭环状态机。
3. 修改 `App_DefaultTask`，只发送 PA0 控制命令。
4. Rebuild，确认 0 错误、0 警告。
5. 不接电机烧录，观察启动日志。
6. 接电机完成低档短时测试。
7. 完成高档阶跃、停止和安全故障测试。
8. 记录最终参数、日志、构建信息和限制。
