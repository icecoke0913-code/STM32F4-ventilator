# STM32F407 智能油烟机主控系统设计

## 1. 项目目标

使用 STM32F407VET6 最小系统板、FreeRTOS、TB6612FNG、带 AB 相霍尔编码器的 JGA12-N20B 直流减速电机、MQ-2、DHT11 和 ST7735S，复现一套可演示、可测试的智能油烟机主控系统。

第一阶段只完成主控功能，不实现 Bootloader。系统需要支持待机、自动、手动和防回流控制，使用编码器反馈与 PID 统一控制电机转速，并通过 ST7735S 显示系统状态。

## 2. 已确认硬件

- 主控：STM32F407VET6 最小系统板
- 开发方式：STM32CubeMX 生成 HAL + FreeRTOS 工程，Keil5 编译和调试
- 电机：JGA12-N20-50B，额定6V、空载300 RPM、减速比50，工作电压范围3～12V
- 编码器：AB 双相增量式磁性霍尔编码器，基础脉冲数 7 PPR，集电极开漏输出
- 电机驱动：TB6612FNG
- 温湿度传感器：DHT11
- 烟雾传感器：MQ-2
- 显示屏：1.8寸 ST7735S，SPI接口，128×160 RGB TFT
- 外部 Flash：W25Q64，第一阶段预留接口
- 输入：PA0 用户按键一个，RST 只用于硬件复位
- 电源：优先使用 3A DC-DC 模块；电机电源与编码器逻辑电源分开，系统共地

## 3. 开发原则

采用分层增量开发。每次只接入一个可独立验证的功能，完成编译、硬件验证和文档记录后再进入下一阶段。

CubeMX 生成代码只负责 HAL、时钟和外设初始化。手写驱动、控制算法和任务代码放在独立目录中，避免重新生成工程时覆盖业务代码。

## 4. 软件架构

```text
传感器输入
MQ-2、DHT11、编码器、PA0按键
              ↓
驱动与采集层
              ↓
共享系统状态 SystemState
              ↓
模式状态机、融合算法、PID
              ↓
TB6612电机输出、ST7735S显示
```

### 4.1 分层职责

- HAL 层：CubeMX 生成的 GPIO、ADC、SPI、TIM、USART 和 FreeRTOS 初始化。
- BSP 层：按键、编码器、电机、MQ-2、DHT11、ST7735S 等板级驱动。
- 服务与控制层：测速、滤波、PID、传感器融合和模式管理。
- 应用层：FreeRTOS 任务、系统状态、单键交互和 UI 页面。

### 4.2 目录结构

```text
firmware/SmartHood/Core/        CubeMX生成
firmware/SmartHood/Drivers/     STM32 HAL/CMSIS
firmware/SmartHood/Middlewares/ FreeRTOS
firmware/SmartHood/MDK-ARM/     Keil5工程
firmware/SmartHood/App/Inc/     应用接口、任务和系统状态
firmware/SmartHood/App/Src/     应用实现
firmware/SmartHood/BSP/Inc/     板级驱动接口
firmware/SmartHood/BSP/Src/     板级驱动实现
firmware/SmartHood/Control/Inc/ PID、状态机和融合算法接口
firmware/SmartHood/Control/Src/ 控制算法实现
docs/                           项目设计、接线和测试记录
```

## 5. 外设和引脚分配

| 功能 | 外设/引脚 | 说明 |
|---|---|---|
| 单用户按键 | PA0 | 板载S1，按下为高电平，内部下拉，10 ms轮询 |
| 编码器A/B | PC6、PC7 | TIM3_CH1/CH2编码器模式 |
| 电机PWM | PB6 | TIM4_CH1，目标频率20 kHz |
| TB6612方向 | PB7、PB8 | AIN1、AIN2 |
| TB6612使能 | PB9 | STBY |
| MQ-2模拟量 | PC0 | ADC1_IN10，输入不得超过3.3V |
| DHT11 | PD0 | 单总线GPIO |
| TFT SPI2 | PB13、PB15 | SCK、MOSI，通过扩展IO和杜邦线连接 |
| TFT片选 | PD7 | ST7735S CS |
| TFT控制 | PD6、PD5 | DC、RST |
| TFT背光 | PD4 | 第一阶段只做开关控制 |
| 板载Flash SPI1 | PB3、PB4、PB5 | SCK、MISO、MOSI，第一阶段预留 |
| 板载Flash片选 | PA15 | F_CS，第一阶段预留 |
| 调试/升级串口 | PA9、PA10 | USART1 |
| SWD调试 | PA13、PA14 | 保留ST-Link接口 |

### 5.1 定时器分工

- TIM3：编码器硬件正交解码。
- TIM4：电机 20 kHz PWM。
- TIM5：DHT11 微秒级计时。
- TIM6：HAL 系统时基。
- SysTick：FreeRTOS 内核时基。

原理图显示开发板存在P2 TFT接口，但用户购买的ST7735S模块接口与P2不一致，本项目不直接使用P2插座。显示屏通过扩展IO连接到SPI2和独立GPIO。板载W25QXX使用PB3/PB4/PB5和PA15，因此CubeMX的SYS调试模式必须选择Serial Wire，以释放JTAG占用的PB3和PB4。

购买的ST7735S模块从左到右丝印为 `BLK、CS、DC、RST、SDA、SCL、VDD、GND`。其中SDA为SPI MOSI，SCL为SPI SCK；模块没有MISO信号，第一阶段使用3.3V供电和3.3V逻辑。

## 6. FreeRTOS任务设计

| 任务 | 周期 | 职责 |
|---|---:|---|
| KeyTask | 10 ms | 按键消抖，产生短按、双击和长按事件 |
| SensorTask | 100 ms | MQ-2采样和滤波；每10次读取一次DHT11 |
| ControlTask | 50 ms | 读取编码器、计算RPM、运行状态机和PID |
| UiTask | 200 ms | 刷新ST7735S显示 |
| DefaultTask | 阻塞等待 | 第一阶段不承担业务功能 |

任务使用按键事件队列传递用户操作。共享的传感器、模式、目标转速和实际转速保存在 `SystemState` 中，并由互斥量保护。编码器由 TIM3 硬件计数，ControlTask 每 50 ms 读取计数增量。

## 7. 用户交互

- 长按约2秒：运行和待机切换。
- 短按：自动、手动、防回流模式循环切换。
- 双击：仅在手动模式下切换190 RPM和220 RPM。
- RST：只用于硬件复位。

短按事件需要等待双击识别窗口结束后再确认，防止一次双击被识别为两个短按。

## 8. 控制策略

所有运行模式最终生成目标转速，由同一套 PID 输出 PWM：

```text
自动模式：温湿度和烟雾融合 → 120～240 RPM
手动模式：固定190或220 RPM
防回流：关闭或固定220 RPM
                         ↓
                    同一个PID
                         ↓
                    PWM占空比
```

### 8.1 自动模式

温度、湿度和 MQ-2 相对烟雾值先归一化，再进行加权融合。初始权重采用温度0.2、湿度0.2、烟雾0.6。融合结果映射为120～240 RPM目标转速。权重和映射范围属于可调参数，最终值以实测为准。

### 8.2 手动模式

提供190 RPM低档和220 RPM高档。双击PA0切换档位，PID负责抵抗电源和负载变化。

### 8.3 防回流模式

使用开启阈值和关闭阈值组成迟滞控制。MQ-2滤波值超过开启阈值时设置220 RPM目标；只有下降到关闭阈值以下才停止，避免临界值附近反复启停。

### 8.4 测速

编码器基础脉冲数为7 PPR，已确认电机减速比为50。使用定时器四倍频计数时，输出轴一圈理论计数为 `7 × 4 × 50 = 1400`。

```text
RPM = 计数增量 × 60 / (采样时间 × 1400)
```

1400计数/圈仍需在M5阶段通过输出轴实测验证，最终测速常量以实测结果为准。

### 8.5 PID

- 采样周期固定为50 ms。
- 输出限制在有效PWM占空比范围内。
- 积分项单独限幅，防止积分饱和。
- 停机、故障或模式切换时清空积分和上次误差。
- 电机启动时允许约300 ms启动增益或最低启动占空比，随后交回PID。

## 9. 异常与安全处理

- MQ-2模块使用5V供电。MQ-2资料给出的测试输出可达到2.5～4.0V，模块AO还可能接近5V，因此AO不得直接接入STM32 ADC；第一版采用约0.6倍电阻分压，并在接线前用万用表验证最大电压。
- MQ-2演示阶段显示ADC值或相对烟雾值，不未经标定声称为ppm。
- DHT11读取失败时保留上一次有效数据，并记录失败次数。
- 编码器在电机已输出PWM时连续无计数，系统停止电机并显示编码器故障。
- 电机电源与编码器电源分开，所有模块共地。
- 电机资料给出的6V堵转电流为0.55A，低于TB6612单通道持续能力，但仍不进行长时间堵转测试。
- 电机电源端增加去耦和储能电容，布线时让电机大电流回路远离ADC和编码器信号线。

## 10. 开发里程碑

1. M1：CubeMX、时钟、调试串口和FreeRTOS最小工程。
2. M2：ST7735S显示驱动。
3. M3：DHT11与MQ-2采集、滤波和预热提示。
4. M4：TB6612与电机开环PWM。
5. M5：编码器硬件测速和RPM标定。
6. M6：PID闭环及190/220 RPM验收。
7. M7：单按键事件识别和三种模式。
8. M8：传感器融合与防回流迟滞控制。
9. M9：UI整合、异常处理和稳定性测试。
10. M10：参数整理、项目文档和简历数据沉淀。

每个里程碑都必须经过编译检查、硬件现象验证和文档记录后才能进入下一阶段。

## 11. 第一阶段验收标准

- Keil5无错误编译，项目无未解释的关键警告。
- 系统可连续运行至少2小时，无死机、任务失联或异常复位。
- ST7735S稳定显示模式、传感器值、目标转速、实际转速和PWM。
- PA0可可靠识别长按、短按和双击，不因按键抖动重复触发。
- 手动模式可稳定控制在190和220 RPM；稳态误差目标为±5%，最终以标定后的编码器参数为准。
- 自动模式可以随传感器相对变化平滑调整目标转速。
- 防回流模式在阈值附近不会频繁启停。
- 断开DHT11或编码器时系统能识别异常，并进入已定义的降级或停机状态。

## 12. 第二阶段边界

第二阶段再实现W25Q64固件暂存、USART + DMA传输、CRC32校验和Bootloader跳转。第一阶段只保留引脚、串口和目录扩展空间，不提前引入升级逻辑。
