# M8A DHT11自动模式实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (recommended) or superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不接入MQ-2的前提下，让DHT11温湿度驱动AUTO的STOP/LOW/HIGH目标，并验证传感器失效时安全停止。

**Architecture:** 新增纯函数`AutoPolicy`计算AUTO候选请求；App层以CMSIS-RTOS互斥量保护最新有效DHT11快照；MotorTask每50ms读取快照并通过扩展后的ModeManager生成最终请求。MANUAL、BACKFLOW、编码器故障和MotorTask唯一PWM所有权保持不变。

**Tech Stack:** STM32F407VET6、STM32CubeMX 6.16.1、STM32CubeF4 1.28.3、HAL、FreeRTOS/CMSIS-RTOS v2、Keil MDK-ARM V5、C。

**设计依据：** `docs/superpowers/specs/2026-08-18-m8a-dht11-auto-design.md`

## 执行前安全约束

- MQ-2 AO/DO在整个M8A计划中保持断开；没有分压器件和万用表时不改变此约束。
- 所有临时自检烧录和DHT11断线测试都必须断开TB6612 VM/9V。
- 禁止安装扇叶、机械负载或执行堵转测试。
- 禁止带电插拔电机、TB6612、编码器或传感器线路。
- 正式M8A固件烧录前确认`APP_M8A_SELF_TEST_ENABLED=0U`。
